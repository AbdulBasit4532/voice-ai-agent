How it works

From "hello" to a saved record in one call

Maya runs the whole intake conversation. Your systems only see clean, validated data.

  1. 01

    You call, Maya answers

    A real U.S. phone number, answered instantly. Maya introduces herself and asks for your name, no key presses.

  2. 02

    Natural conversation

    Answer in any order, correct yourself mid-sentence, or ask to start over. Maya spells names back and checks each detail as you go.

  3. 03

    Read-back and confirmation

    Before anything is saved, Maya reads the full record back and asks you to confirm or change any field.

  4. 04

    Saved, confirmed, done

    The record lands in the database and appears in the dashboard and API immediately. "You're all set, Sarah."

What Maya collects

The standard U.S. patient demographic set

Required fields are always collected. Optional ones are offered once, so callers opt in instead of being interrogated.

Required

  • Name letters, hyphens and apostrophes; spelled back
  • Date of birth real date, not in the future
  • Sex Male, Female, Other, Decline to answer
  • Phone valid 10-digit U.S. number
  • Address street, city, 2-letter state, ZIP or ZIP+4

Offered as opt-in

  • Email format-checked
  • Insurance provider and alphanumeric member ID
  • Emergency contact name and phone
  • Preferred language defaults to English
  • Apartment / unit if applicable
"I can also collect your insurance information, emergency contact, and preferred language. Would you like to provide any of those?"

Built for the messy real world

What happens when things go wrong

Every edge case gets a spoken, specific response, never silence.

🗓️

Invalid date of birth

"Born in 2099"? Maya re-asks for just the date, with an example of the format.

✏️

Corrections mid-call

"Actually it's D-A-V-I-S, not D-A-V-I-E-S." The field is replaced, re-validated and re-confirmed.

👋

Returning callers

A known phone number triggers "It looks like we already have a record for you. Update it instead?"

🔁

Start over

Say "scratch that" and Maya discards everything and begins again from your name.

⚠️

Database failure

Maya tells the caller honestly that the record couldn't be saved and offers to retry. She never fakes success.

🌎

"Hablo español"

Multilingual transcription lets Maya switch languages mid-call while keeping data in a standard format.

For engineers

Everything Maya saves is one request away

A small REST API with a consistent { data, error } envelope, server-side validation, soft deletes and filters. The voice agent and the API share the same schema, so nothing slips through.

  • GET/patientslist · filter by last_name, date_of_birth, phone_number
  • GET/patients/:idsingle record
  • POST/patientscreate · 201
  • PUT/patients/:idpartial update
  • DELETE/patients/:idsoft delete
